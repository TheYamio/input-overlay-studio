## Собери свой оверлей

| Возможность | Что можно сделать |
| :--- | :--- |
| **Рисунок на кейкапах** | Наложи одну общую картинку на клавиши. Промежутки, скругления и вырезы произвольных форм останутся нетронутыми. |
| **Настройка каждой детали** | Перемещай и растягивай модули и отдельные клавиши. Загружай SVG-формы, меняй подписи, цвета, шрифты и рамки. |
| **Живая реакция на ввод** | Настраивай анимации нажатия, подсветку, время эффектов и след мыши. Проверяй результат с реальным вводом или в Demo. |
| **Параметры твоего сетапа** | Показывай DPI, чувствительность, примерную дистанцию движения мыши и см/360 с игровыми профилями. |
| **Готовая отправная точка** | Выбери стандартную композицию или авторский пресет. Примени только цветовую тему к своему расположению либо замени композицию целиком. |
| **Сохранение и перенос** | Отменяй изменения, сохраняй свои пресеты и переноси профили вместе с изображениями на другой компьютер. |

Доступны 12 встроенных языков интерфейса и импорт собственных переводов. Твои подписи сохраняются в исходном виде.

## Быстрый старт

1. **[Скачай Windows x64 ZIP](https://github.com/TheYamio/input-overlay-studio/releases/latest)** и распакуй весь архив.
2. **Запусти Input Overlay Studio.** Мастер поможет выбрать расположение и проверить ввод. Для работы нужен [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section).
3. **Настрой оформление.** Укажи DPI и чувствительность в игре, затем собери свой оверлей.
4. **Подключи OBS.** Нажми **Copy OBS URL**, добавь **Источник браузера** и вставь ссылку. Рекомендуемый начальный размер — **1920 × 1080**.

Во время работы оверлея оставляй Studio запущенной. После закрытия окна приложение остаётся в трее; полный выход — **Exit** в меню трея.

[Подключение к OBS →](docs/OBS_SETUP.md)

<summary><strong>Данные и приватность</strong></summary>

Повседневная работа не требует интернета. Захват ввода выполняется локально; по умолчанию оверлей подключается к твоему компьютеру. Телеметрии, истории текстового ввода и внедрения DLL в игры нет.
