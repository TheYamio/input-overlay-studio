# Визуальные возможности

## Общая картинка для нескольких модулей

1. Выберите Keyboard либо Mouse Buttons и загрузите изображение в Keycap Image.
2. Откройте **Shared artwork across modules** и отметьте другие клавиатурные/мышиные модули. Рисунок и все настройки изображения выбранного модуля станут общими для отмеченных участников.
3. Настраивайте положение в **Position & scale image**. Предпросмотр показывает всю группу.
4. Настройки изображения любого участника меняют всю группу одной операцией Undo.

Область группы вычисляется по фактическим поверхностям кейкапов и масштабам модулей.

Cover/Contain вписывают картинку во всю область группы. Перемещение/добавление участника может изменить эту область и масштаб вписывания. В группах Original/Tile и X/Y используют координаты сцены; отдельный модуль использует локальные единицы раскладки.

## Полный редактор изображения

Слева расположен предпросмотр, справа — отдельно прокручиваемые панели Placement и Image & color. Результат остаётся видимым при настройке фильтров.

- Перетаскивание и колесо меняют положение и масштаб изображения. Стрелки в области предпросмотра сдвигают его на 1 единицу, Shift — на 10.
- Center image обнуляет смещение; Flip horizontally / Flip vertically отражают рисунок.
- Preview zoom увеличивает рабочий обзор до 150/200%; полосы прокрутки перемещают обзор.
- Source guide показывает полупрозрачный немаскированный ориентир исходника.
- Compare original показывает настройки на момент открытия окна.
- Opacity, blending, brightness, contrast, saturation, tint и поведение при нажатии доступны в том же окне. Reset placement и Reset image adjustments сбрасывают соответствующие группы параметров.
- Apply image placement применяет весь черновик одной операцией Undo. Cancel и Esc его отбрасывают.

## Предпросмотр состояний

В Properties → **Key/button preview** доступны Input, Idle, Pressed, Analog, Scroll up и Scroll down. Для Analog есть отдельная глубина 0–1. Input возвращает обычный Live/Demo.

В редакторе картинки предусмотрен такой же изолированный предпросмотр. Он позволяет настроить pressed text, glow, Analog Fill и режим картинки при нажатии без удержания физической клавиши.

## Композиции и настоящие миниатюры

В Presets семь разных композиций: Essential — компактная FPS; Competitive — расширенная клавиатура и отдельный trail; Obsidian — исходная универсальная; Neon — крупная стримерская; Glass — вертикальная справа; Clean Recording — минимальная горизонтальная; Classic Input — вертикальная слева.

**Apply theme** меняет оформление текущей геометрии. **Reset layout** восстанавливает полную заводскую композицию, включая видимость, набор клавиш и компоновку мыши. Оба действия отменяются обычным Undo; DPI и чувствительность профиля сохраняются.

## Сохранение и перенос

Сохраните композицию в библиотеке пресетов или экспортируйте её вместе с изображениями. Для переноса всех профилей используйте Export JSON. Подробности — в [инструкции по сохранению](SAVING_AND_SYNC.md).
