## Что проверяют новые сценарии

- Модуль с кавычками, квадратными скобками и обратной косой чертой в ID можно перетаскивать и менять размер.
- Заблокированный модуль сохраняет полный transform при числовом вводе и переключении Mouse Diagram.
- Клавиши остаются внутри вычисленных границ при gap 0/8/30; общий artwork использует те же границы.
- Выходящие за сцену модули нормализуются при импорте и загрузке без изменения валидных размеров.
- Реальные PNG/JPEG/WebP распознаются, ложный Base64, несовпадающие размеры и обрезанный PNG отклоняются. При неудачном импорте текущая конфигурация остаётся прежней.
- Длинный текст вписывается по обеим осям, а ручной размер ограничивается рамкой модуля.
- Отложенный decode старой конфигурации не отменяет более новое сообщение сервера.
- Отключённый HTTP, занятый порт и отсутствующая overlay-страница дают объяснение и не меняют буфер обмена.

## Практические пределы проверки

Физическая периферия 1–8 kHz, игры/античит, длительная запись, Linux runtime и аварийное отключение питания в этом прогоне не проверялись. Минутный стресс-тест предыдущей версии не повторялся. В сборке остаются семь предупреждений старого неиспользуемого updater и две удаляемые Rollup аннотации Zod.
