**Всего: 169 проверок**, плюс проверка соответствия JSON schema текущей Zod-схеме. Контрольный снимок интерфейса создан и просмотрен на 1366×768. Проверяется отсутствие горизонтального overflow, доступность инспектора, увеличенный режим и попадание всех поверхностей клавиш внутрь рабочего обзора.

Новые сценарии покрывают согласованный выбор клавиши на холсте/в инспекторе, drag/resize одним Undo, Esc и Ctrl+Z для отмены незавершённого жеста, nudge с удержанием стрелки и Shift, защиту Lock position, browser/native назначение и отмену захвата, сохранение собственной подписи, выборочное наследование, clipboard между клавишами и мышью, bulk paste и Undo, неизменность подписи/кода/геометрии при переносе стиля, скрытые кнопки, группировку slider и текста, дублирование и reload.

Browser/editor/customization используют синтетический transport. Native smoke использует конечный exe со встроенным production frontend; OBS подключается к release backend и проверяет настоящий CEF. Аппаратная приёмка конкретных клавиатур/мышей, разных раскладок Windows, игры/античит и длительная нагрузка в этот этап не входят.

Стабильный portable 0.3.2 остаётся в `release/Input Overlay Studio` с исходным SHA-256 `72ebdd9cb4e4781f994a630a0be8b9615ea609266816aa6f703e27b6c6c304aa`.
