# Архитектура Input Overlay Studio

## Компоненты

- `studio/src/main.tsx` — React-редактор: профили, слои, холст, история и автосохранение. Компоненты настроек и изображения лежат рядом.
- `studio/src/core/` — схема документа v2, миграция, ввод, математика чувствительности, геометрия, растровые изображения, пресеты, WebSocket и хранение.
- `studio/src/renderer/` — общий DOM/Canvas-рендерер Studio и OBS. `overlay.ts` запускает прозрачный источник без React-редактора.
- `ws-server/src-tauri/src/` — Tauri-приложение, Windows Raw Input, Linux evdev, аналоговые HID-устройства, WebSocket, локальный HTTP и сохранение.
- `scripts/build-studio.ps1` — сборка и упаковка дистрибутива.

## Поток данных

Захват передаёт события через ограниченную очередь. Движение агрегируется примерно до 125 WebSocket-пакетов в секунду; длина исходного пути сохраняется отдельно. Снимки восстанавливают удержания после переподключения. Клиент пропускает устаревшие события по sequence.

InputEngine обновляет состояние без React-render на каждый пакет. Scene хранит узлы и ограниченный буфер следа, обновляет только изменившееся и останавливает кадровый цикл после затухания.

Документ проверяется Zod, а нативный сервер использует генерируемый JSON-контракт. Сохранение учитывает revision: устаревшая запись вызывает конфликт. Конфигурация OBS доступна без открытого редактора. Токен соединения не входит в экспорт профиля.

## Веб-ресурсы

Vite собирает `studio/dist`. Tauri встраивает его напрямую и открывает `index.html`. `build.rs` встраивает ту же сборку в HTTP-сервер под `/studio/`. Адрес `/` перенаправляет в `/studio/index.html`; источник OBS — `/studio/overlay.html`. Старые браузерный редактор, окно настроек и сторонний updater исключены.

## Данные

По умолчанию используется `%LOCALAPPDATA%/InputOverlayStudio`. Существующий portable `config.json` сохраняет portable-режим. Явный `INPUT_OVERLAY_STUDIO_DATA_DIR` задаёт изолированные данные и экземпляр приложения. Браузер хранит автономный черновик, нативный сервер — настройки и резервные копии.
