# v0.4.0 — 21 октября 2026

Стабильный релиз объединяет этапы 0.3.3-dev.1–dev.3; отдельная стабильная 0.3.3 не выпускалась.

- Прямое редактирование клавиш на холсте, назначение физическим нажатием, копирование/массовая вставка стилей, сброс переопределений и один Undo на жест.
- Единая полупрозрачная картинка для группы клавиатур и кнопок мыши, прозрачные промежутки, отражение X/Y и полный редактор изображения с предварительным просмотром и отменой.
- Изолированный просмотр idle/pressed/analog/scroll, семь разных заводских композиций и живые миниатюры пресетов.
- Пропуск неизменившихся кейкапов, индексы DOM и кеширование Distance. Обновление одного модуля в тесте 3200 клавиш ускорено примерно в 11,5 раза; экстремальные раскладки по-прежнему могут терять плавность.
- Сохранён JSON v2; native проверяет целостность групп и поддержку новых визуальных полей.
- Собственная иконка Input Overlay Studio для приложения, окна, трея, редактора и favicon.
- Windows x64 portable ZIP включает exe, необходимые DLL, лицензии и документацию. Рядом публикуются исходники и SHA-256.
- [Финальная проверка релиза](TEST_RESULTS_0.4.0.md), [подробные измерения и ограничения](PERFORMANCE_0.3.3.md).

Следующие записи — история локальных этапов до публикации v0.4.0.

# v0.3.3-dev.3 — локальные проверки и оптимизация, 21 октября 2026

- Scene пропускает неизменившиеся клавиши/кнопки, учитывая общие координаты и замену данных изображения с прежним asset ID.
- Поиск DOM-клавиш и их control заменён индексами; устранён квадратичный обход при обновлении больших раскладок.
- Кешируются форматы Distance, одинаковый округлённый текст не записывается заново, скрытый счётчик не обновляет DOM. Убран лишний сброс transform перед измерением текста.
- Добавлены воспроизводимые production-замеры CPU, layout/style, JS heap и жизненного цикла редактора; Windows-счётчики процессов и GPU, actual OBS soak и проверка закрытия native-окна.
- Подробные результаты и ограничения: [PERFORMANCE_0.3.3.md](PERFORMANCE_0.3.3.md). Изменения остаются локально, без commit/push.

# v0.3.2 — 21 октября 2026

- Исправлено перетаскивание модулей с кавычками и специальными символами в ID.
- Границы клавиатуры и общего изображения рассчитываются по фактическим размерам кейкапов после Key gap.
- Импорт и загрузка возвращают выходящие за сцену модули в кадр, сохраняя их размеры, подписи и оформление.
- Lock position защищает координаты и размер через числа, drag/resize и переключение вида мыши.
- PNG/JPEG/WebP проверяются по настоящим заголовкам и размерам, затем декодируются; повреждённый импорт не заменяет текущие настройки. Native также проверяет содержимое изображений с ограничением памяти и кешем проверенных assets.
- Distance/Sensitivity подгоняют длинный текст внутри модуля; при ручном размере содержимое ограничивается рамкой. Неприменимые параметры нажатия и типографики скрыты.
- Copy OBS URL проверяет состояние native HTTP и наличие overlay entry; отключение HTTP, занятый порт и недоступная страница показываются отдельно.
- Дублирование длинных имён не превышает лимит и сохраняет целые Unicode-символы. Старые frontend bundles больше не накапливаются при staging.
- Добавлены editor regressions и их запуск в Windows CI. Синхронизация защищена от запоздавшего декодирования старой конфигурации.

# v0.3.1 — 20 октября 2026

- Сохранение по базовой версии документа, явное разрешение конфликтов двух редакторов, сохранение черновика и базовой версии после перезапуска.
- Последовательная отправка правок с привязкой подтверждений к конкретному запросу; повторное соединение при отсутствии подтверждения.

- Единый бюджет компактного UTF-8 JSON, компактный экспорт с обратным импортом.
- Дисковая запись отделена от блокировки документа для input; атомарная замена файла дистанции.
- Исправлена обработка квоты localStorage и ротация резервных копий при подтверждении сохранения.
- OBS больше не инициирует запись миграции. Протокол 4 требует совместимого редактора для записи.
- Подробности: [Сохранение и синхронизация](SAVING_AND_SYNC.md).

# Изменения

## 0.2.0 — 20 октября 2026

- OBS вписывает сцену 1920×1080 в фактический размер Browser Source с сохранением пропорций и прозрачными полями.
- Редактор: шесть команд выравнивания, Reset position, привязка к краям и центрам соседних модулей с направляющими.
- Изменение свойств сохраняет Canvas, текущий след, камеру и существующие элементы клавиш. Переключение профиля начинает новую сцену.
- Протокол 3: снимок удержаний через input queue, номера событий, восстановление после reconnect без воспроизведения фиктивных кликов. На Windows цифровое состояние сверяется с ОС.
- Исправлены extended scancode для правых Ctrl/Alt и сброс клавиш/траектории при обновлении общей дистанции.
- Проверена интеграция в настоящем OBS 32.2.2: прозрачность, 1080p/1440p, live profile updates, reconnect без редактора.
- Добавлены тесты геометрии, сохранения состояния рендерера, порядка snapshot/events и реального OBS/CEF.
