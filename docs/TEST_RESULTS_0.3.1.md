## Поведение и ограничения

- Старый документ и его версия остаются текущими, если запись на диск завершается ошибкой.
- Старый клиент не может перезаписать документ без base_revision. Новый редактор требует сервер 0.3.1 для записи.
- Конфликт разрешается выбором целого документа; слияния отдельных полей нет.
- Черновик и его базовая ревизия записываются одной операцией localStorage. При недоступном хранилище редактор показывает ошибку; перед закрытием нужен экспорт.
- Крупные assets и Undo пока остаются в документах. Оптимизация IndexedDB/истории выделена в следующий этап.
- Дистанция сохраняется атомарной заменой раз в три секунды. Гарантия финального flush при аварийном завершении не заявляется.
- Минутный стресс-тест предыдущей версии не повторялся. Физическая периферия 1–8 kHz, игры/античит, длительная запись и поведение при отключении питания не проверены этим прогоном.
- Семь предупреждений Rust относятся к старому неиспользуемому updater; две аннотации Zod удаляются Rollup при успешной сборке.
