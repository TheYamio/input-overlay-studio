## Новые сценарии

- Общая картинка непрерывна между клавиатурой и мышью разного масштаба. Пиксели в промежутках прозрачны; скрытые участники сохраняют координатную систему, пустые не расширяют область.
- Изменения настроек и отражения распространяются на группу. Undo возвращает всех участников; выход из группы сохраняет независимую картинку. Пресеты при импорте получают новые идентификаторы групп.
- Поворот Tile заполняет очень широкие и очень высокие поверхности без пустых краёв. Проверены пиксели, горизонтальное и вертикальное отражение, коррекции и поведение при нажатии.
- Полный редактор изображения сохраняет настройки только после Apply, одной операцией Undo. Проверены Cancel, сравнение, вспомогательный исходник и состояния нажатия/Analog/колеса без вмешательства в реальные события и OBS.
- Сохранённые пресеты отображают настоящий Scene. Семь фабричных композиций отличаются геометрией; Apply theme сохраняет текущую геометрию. Проверены освобождение blob URLs, reload и работа диалога на 1366×768.
- Новый редактор блокирует отправку групп/отражений старому backend без capability `studio_visuals`, сохраняя локальный черновик. Обычные прежние документы продолжают сохраняться.
- Реальный Rust backend сохраняет согласованные группы и отражения на диск. Реальный OBS/CEF выводит общий рисунок через несколько модулей с прозрачными промежутками и корректным отражением.

Browser/editor/visual/sync/customization используют синтетический transport. Native использует конечный portable exe со встроенным production frontend; OBS подключается к release backend с теми же байтами exe. Снимки расширенного редактора и настоящих миниатюр просмотрены. Аппаратная приёмка разных клавиатур/мышей и раскладок Windows, игры/античит и длительная GPU-нагрузка в этот этап не входят.
