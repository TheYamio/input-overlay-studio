<p align="center"><a href="https://github.com/TheYamio/input-overlay-studio/releases/download/v0.6.3/Input-Overlay-Studio-0.6.3-Windows-x64.zip"><strong>⬇ Download for Windows x64</strong></a></p>

> **Custom language packs no longer overwrite built-in translations or collide with other imports. This update also improves translation coverage and fixes editor focus and small-window dialogs.**

### Highlights
- **Safer custom translations.** Each import gets an independent package; built-in languages remain protected, even when names or locale codes match.
- **Complete import/export workflow.** Export the selected translation or the English template. Delete a custom package with confirmation and safely fall back when the active package is removed.
- **Safer saving.** Locale selection and packages are saved together; a failed write preserves the previous state.
- **Interface polish.** Improved translations, shortcut messages, editor hints, focus restoration and dialogs on smaller windows.

### Install in OBS
1. [Download the Windows x64 ZIP](https://github.com/TheYamio/input-overlay-studio/releases/download/v0.6.3/Input-Overlay-Studio-0.6.3-Windows-x64.zip) and **extract the entire archive**.
2. Run `Input Overlay Studio.exe` and keep the bundled DLLs next to it. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) is required.
3. In Studio select **Copy OBS URL**. In OBS create a **Browser Source** at **1920 × 1080** and paste the URL. The transparent overlay can keep running after the editor window closes.
