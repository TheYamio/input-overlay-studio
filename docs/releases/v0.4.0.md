> **Build more expressive input overlays with direct key editing, shared keycap artwork, live input previews and seven ready-made layouts.**

### Highlights
- **Edit directly on the canvas.** Reposition keys, bind physical inputs and copy styles with predictable Undo behavior.
- **Shared keycap artwork.** One translucent image across keyboard and mouse buttons, preserving transparent gaps; transform and color-adjust it in the image editor.
- **Preview before going live.** Test pressed, analog and wheel states; start from seven factory compositions.
- **Performance improvements.** Avoid redundant keycap redraws and distance updates in large layouts.

### Before updating
The release notes document JSON format **v2**. A Windows x64 portable ZIP is attached. Unlike later releases, this historical release has **no separate source ZIP or checksum file attached**; tagged source can be accessed from GitHub.

### Install in OBS
1. [Download the Windows x64 ZIP](https://github.com/TheYamio/input-overlay-studio/releases/download/v0.4.0/Input-Overlay-Studio-0.4.0-Windows-x64.zip) and **extract the entire archive**.
2. Run `Input Overlay Studio.exe` and keep the bundled DLLs next to it. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) is required.
3. In Studio select **Copy OBS URL**. In OBS create a **Browser Source** at **1920 × 1080** and paste the URL. The transparent overlay can keep running after the editor window closes.
