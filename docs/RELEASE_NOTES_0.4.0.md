## Input Overlay Studio v0.4.0

Этот стабильный выпуск объединяет улучшения редактора, новые визуальные возможности и оптимизацию, разрабатывавшиеся как 0.3.3-dev.1–dev.3.

- Редактирование клавиш прямо на холсте, назначение физическим нажатием, копирование стилей и один Undo на жест.
- Общая полупрозрачная картинка через клавиши и кнопки мыши с прозрачными промежутками; полный редактор изображения, отражение, смешивание и цветокоррекция.
- Предпросмотр нажатий, analog и прокрутки; семь заводских композиций и миниатюры пресетов.
- Обновление только изменившихся элементов, ускорение больших раскладок и снижение лишних обновлений Distance.
- Собственная иконка приложения, окна, трея и Studio.

### Установка

Скачайте **Input-Overlay-Studio-0.4.0-Windows-x64.zip**, распакуйте весь архив и запустите **Input Overlay Studio.exe**. Оставьте обе DLL рядом с exe. Нужен Microsoft Edge WebView2 Runtime. В Studio выберите **Copy OBS URL** и добавьте Browser Source 1920×1080 в OBS. Редактор можно закрыть, оставив приложение в трее.

Настройки хранятся в `%LOCALAPPDATA%/InputOverlayStudio`; существующий portable config рядом с exe сохраняет прежний режим хранения. Формат документа остаётся v2. Перед обновлением можно экспортировать свой документ из Studio.

### Проверка и ограничения

201 функциональная проверка: frontend, Rust, browser, синхронизация, редактор, кастомизация, визуальные возможности, настоящий native exe и OBS/CEF. Финальная версия и иконка проверены повторной сборкой. Подробности: [результаты v0.4.0](https://github.com/TheYamio/input-overlay-studio/blob/v0.4.0/docs/TEST_RESULTS_0.4.0.md).

В измеренной обычной сцене OBS работал при 60 FPS без пропущенных кадров. Экстремальные раскладки из тысяч клавиш могут терять плавность. Синтетический тест 8000 Hz не заменяет проверку физического USB-устройства; длительная приёмка с игрой/стримом и аналоговыми клавиатурами остаётся открытой. [Методика, цифры и ограничения](https://github.com/TheYamio/input-overlay-studio/blob/v0.4.0/docs/PERFORMANCE_0.3.3.md).
