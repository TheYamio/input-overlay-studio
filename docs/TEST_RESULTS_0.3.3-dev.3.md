Всего **201 функциональная проверка**. Дополнительно проверены production-замеры 8 сценариев, 12 обновлений трёх размеров сцены до/после оптимизации, полноценная 100-key клавиатура, предельные 3200 клавиш, 25 циклов открытия редакторов после прогрева, native/WebView2 и закрытие окна, настоящий OBS/GPU с cooldown и 180 секунд синтетического 8000 Hz ввода.

Нет ошибок runtime в пройденных сценариях. Обычные сцены плавные, обновление одного модуля ускорено. Предельная сцена из 3200 клавиш имеет long tasks и просадки; длительная GPU-приёмка в игре ещё не выполнена. Все цифры, границы измерений и необработанные данные: [PERFORMANCE_0.3.3.md](PERFORMANCE_0.3.3.md).

Browser/visual/sync/editor/customization используют синтетический transport. Native 11/11 выполнен с `STUDIO_NATIVE_RESOURCES=1` на exe из отдельного portable-каталога; OBS подключается к тому же бинарному build.
